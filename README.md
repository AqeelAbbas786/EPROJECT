# eProject - Static Website

Welcome to the **eProject** website repository! This is a static, single-page website created to showcase the details of your eProject portfolio. The website is built using only **HTML** and **CSS** and provides essential project details in a clean and simple layout.

## About the Project

The **eProject** website serves as a simple online platform to showcase your portfolio, highlighting the work you've done. It is a static website that presents important project information in a visually clean and accessible manner. Features include:

- **Project Descriptions**: Information about each project you’ve worked on.
- **Skills & Technologies**: A list of the skills and technologies you have experience with.
- **Contact Information**: A section for visitors to get in touch with you.

### Features

- **Static Layout**: The website is built as a single, static page.
- **Project Details**: A simple and clear overview of each of your projects.
- **Skills Overview**: Displays the skills and technologies you are proficient in.
- **Contact Section**: A basic area for visitors to contact you for inquiries or collaboration.

## Technologies Used

This website is built using the following technologies:

- **HTML5**: For structuring the content and layout.
- **CSS3**: For styling the website and creating a visually clean design.

Since the site is non-responsive, it is designed to look best on desktop screens. No media queries or Bootstrap are used.
